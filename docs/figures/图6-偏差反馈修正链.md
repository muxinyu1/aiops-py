# 图 6:偏差反馈修正链(案例研究图)

## 这张图要表达什么

"执行路径偏差反馈"如何工作:Agent 首次触发失败(500)后,通过读日志堆栈→沿堆栈读源码→查库确认,发现"办理流程任务要求业务单据记录存在"这一隐藏前置(位于 5 层调用链深处,静态分析几乎不可能发现),修正后命中 sink。这是"运行时信息是静态分析无法替代的"的直接证据。

## Sink 源码(WorkflowGlobalListener.determineFlowStatus,L257-270)

```java
private String determineFlowStatus(Instance instance) {
    String flowStatus = instance.getFlowStatus();
    if (StringUtils.isNotBlank(flowStatus) && BusinessStatusEnum.initialState(flowStatus)) {
        log.info("流程实例当前状态: {}", flowStatus);
        return flowStatus;
    } else {
        Long instanceId = instance.getId();
        if (flwTaskService.isTaskEnd(instanceId)) {          // ← 命中条件: 全部任务办理完成
            String status = BusinessStatusEnum.FINISH.getStatus();
            flwInstanceService.updateStatus(instanceId, status);
            log.info("流程已结束，状态更新为: {}", status);   // ← sink L270
            return status;
        }
        return null;
    }
}
```

## Agent 实际修正链(取自 wf_listener_end_v3.json 真实序列,#59-100)

**阶段 1:首次尝试失败**
```

    → HTTP 200 {"code":500,"msg":"发生未知异常，请联系管理员"}
```

**阶段 2:偏差诊断(读日志堆栈 ×3,逐步加大深度)**

**阶段 3:沿堆栈定向源码排查(11 次调用)**

```
#68-69 read_source TestLeaveServiceImpl.java      ← 堆栈指向: 办理回调处理 TestLeave
#71 read_source WorkflowServiceImpl.java
#73 read_source FlwCommonServiceImpl.java
#74 read_source FlwTaskServiceImpl.java
#79 read_source TestLeaveBo.java                  ← 确认业务单据的字段
```

**阶段 4:第一次修正仍失败(405 偏差)**
```
#81 send_http POST /leave/add → HTTP 405 "Request method 'POST' is not supported"
#82 read_source TestLeaveController.java          ← 读 Controller 确认正确路径与方法
```

**阶段 5:修正后命中**
```

```

## 建议画法

**带反馈箭头的循环时序图(推荐)**:
- 主轴为时间步(#59→#100),每步一个小方块按工具着色(send_http 橙 / read_logs 红 / read_source 蓝 / query_db 绿)
- #59 的 500 用红色标记,从这里画一条"偏差反馈"回路箭头指向 #60-79 的诊断块
- #81 的 405 再画一个小回路指向 #82
- #83-85 三个绿色 200 连成命中段,末端标注 sink 日志行
- 两个回路分别标注:"偏差=500 未知异常 → 堆栈指向 TestLeaveServiceImpl" 和 "偏差=405 → Controller 路径修正"

**信息框(图右上角或底部)**:"该隐藏前置(办理回调要求业务单据存在)位于 TestLeaveServiceImpl.processHandler → TenantHelper.dynamic → lambda 5 层调用链,仅在运行时异常堆栈中显形"。
